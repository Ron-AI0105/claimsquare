# Claimsquare

### Employee-first assistance and career support

Claimsquare is a project founded by Ronaldo Laishram and operated
with his co-founder. It brings independent PF/ESIC assistance and
career-support services together in one website.

Website: https://claimsquare.in

## What the project offers

### PF & ESIC assistance
- Information about PF claims, rejected claims and transfers.
- Guidance for UAN, KYC and ESIC-related questions.
- Employee accounts and profile preferences.
- Assistance-request tracking and an authorized founder review queue.

### Career support
- Resume Building — ₹199.
- Resume + Customized Interview Preparation — ₹499 total.
- Personalized interview questions and suggested answers.
- Likely follow-up questions and questions to ask the interviewer.
- Google Forms intake for career-service requests.

The interview bundle provides written preparation, not a live mock
interview. Neither service guarantees a job.

## Technology

- HTML, CSS and JavaScript
- Vite
- Supabase authentication and database
- Cloudflare Pages hosting
- Google Forms and Google Sheets for career-service intake

## Project status

Public test site / work in progress.

PF/ESIC request intake and document uploads remain disabled.
There is no online checkout. Some workflows are still being developed
and tested.

Claimsquare is independent and is not affiliated with EPFO, ESIC,
or any government authority. Official claim outcomes are not guaranteed.
